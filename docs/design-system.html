Phase & calendar

The four phase colours never follow the mood. They were chosen by measurement, not by eye: DT22 compared every phase colour against every colour in every mood palette in CIELAB and found three of four were byte-identical to a mood colour — ΔE 0.0, the same paint. audit:colour now fails the build below ΔE 18.

A fact is solid. An estimate is a wash.

Every calendar fill is composited against the ground ahead of time and drawn opaque — never an 8-hex alpha over a drifting bloom, which is how the audit measured a token while the eye saw something else (DT23). These are the real values the grid paints, from src/theme/blend.ts:

Why the ovulation day keeps the fertile fill. It used to replace it with a brighter one of the same hue, so a day that was two things looked like one. Shape carries the single day; colour carries the span. And ink is never assumed — inkOn(fill) picks white or ground per cell.

Laws

Each of these cost a 25-minute build and a round with the owner. Four of them are now enforced by audits that fail npm run test:all.

AuditFails when
audit:safeareaa scrolling screen misses an inset at either end, or a route uses presentation:'modal'
audit:coloura phase colour lands within ΔE 18 of any mood colour · phases within ΔE 40 of each other · a logged day within ΔE 20 of an estimate
audit:uia tappable has no press handler or no accessibility props
audit:silenta catch swallows an error behind if (__DEV__) console.warn — __DEV__ is false in the owner's build, so that is silence
test:rangesthe dated calendar list disagrees with the grid it describes, cell for cell, over 200 random months

And the ones a human has to hold

A row that toggles something is tappable across its full width and never under 48pt tall. No empty shells — a feature with no data shows one honest line, never a chart-shaped skeleton. Non-diagnostic copy, always: “many people report”, never “your body does X”. No invented statistics; insight speaks about the user's own history with the sample size attached, and stays silent at n=1. The fertile window never appears without its caveat, verbatim.
